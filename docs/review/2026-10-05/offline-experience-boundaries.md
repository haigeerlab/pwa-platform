# 导航兜底与自动恢复：优化前边界证据

日期：2026-10-05。状态：问题已复现，尚未修复；本记录不是优化后验收通过证明。

## 方法与基准

- 使用从 PC 宿主公开部署读取的原样 worker 和离线页，在本机受控 HTTP 服务及真实 Chrome 中运行。
- worker SHA-256：`0ac512a977296501d5b145171fd7aae85f4977c44f5753851dbac79abfd0ad39`。与此前同日检查文件一致；不据此推断它对应的 NPM 版本。
- 先验证 worker 已控制页面，再通过服务端延迟、关闭连接及独立控制 HEAD 探测响应制造边界。
- 原样配置为导航阈值 5 秒、只预缓存离线页、业务运行时缓存关闭。默认离线页在可见时每 10 秒探测 worker 文件，单次 3 秒超时，一次成功即重新加载。
- 复现服务与浏览器测试标签已关闭；没有修改宿主线上部署或平台实现。

## 结果

| 场景 | 观察 | 结论 |
| --- | --- | --- |
| 文档 4 秒后返回 200 | 显示业务文档 | 未触发兜底。 |
| 网络可达，文档 6 秒后返回 200 | 约 5 秒展示离线页；服务器随后成功返回 | 慢文档可能被描述为断网。 |
| 不足 1 秒的连接失败窗口，此后恢复 | 浏览器最初的请求及内部重试均在窗口内失败，立即显示离线页；随后自动恢复 | 未提供应用层的有界重试或宽限。 |
| 文档持续连接失败，worker HEAD 快速返回 200 | 初次导航后自动重载 5 轮；间隔约 10.19、10.31、10.28、10.23、10.28 秒 | 恢复探测成功不等于业务可用；重载循环已复现。 |
| 文档失败，worker HEAD 延迟 4 秒 | 至少两轮探测后仍在离线页，未新增文档导航 | 3 秒探测超时能阻止这类重载。 |
| 文档返回 HTTP 500 | 显示服务器错误文档 | 不进入离线兜底。 |
| 文档正常，API 503、图片失败 | 业务文档保留并显示资源失败 | 不会自动整页离线；也不能保证页面完整。 |

## 限制

本地服务关闭 TCP 连接模拟短暂读取失败，不是对真实网络丢包的抓包测试。真实丢包可能被 TCP 重传恢复。本地 origin 与真实宿主不同；本证据证明原样部署代码具备上述边界，不证明宿主线上已经发生同类事故。

未覆盖手机、精确 5 秒的竞争边界、响应头到达后响应体长期挂起、所有宿主路由及真实运营网络。后续需将场景纳入仓库可重复测试，并按既有浏览器矩阵验收。自动化、包分发与实际宿主升级证据应分别记录。
