# ADR-0028：首批 npm 预发布只覆盖 Vite、Vue 与 React 的依赖闭包

## 状态

已接受（2026-09-20；组织名 `pwa-platform` 与 MIT 许可由项目所有者确认）

## 背景

ADR-0001 将 `@pwa-platform/*` 作为私有占位 scope，允许未来统一迁移。现已创建同名 npm 组织。九个相互依赖的包需要一起分发，外部项目才能安装 Vite 插件与框架绑定；移动端原生安装和生产部署证据仍未闭合。

## 决策

首批九包按统一版本 `0.1.0-beta.0`、MIT、公开 npm registry 和 `next` 标签准备。根项目、测试包、Nuxt 和可选模块不发布。内部包必须作为传递依赖出现在 registry，但业务应用只把 Vite 插件和 Vue/React 绑定当作常规接入入口。

本决策只准备分发，不批准实际上传或业务应用生产部署。九包须在 tarball 中具备真实依赖版本、完整导出与许可证；发布从依赖底层向上执行。后续版本遵循 SemVer，改动公开契约前给出升级说明。

## 影响

本 ADR 为 ADR-0001 的发布迁移决定增加首批范围，不修改其历史事实。npm 包与业务应用的生产发布门禁分别记录；后者继续遵守发布运行手册与浏览器矩阵。

## 后续状态（2026-09-20）

所有者在配置与验收完成后明确要求继续，九包已发布 `0.1.0-beta.0`；见[发布记录](../../tasks/package-distribution/release-2026-09-20.md)。npm 首发还自动设置了 `latest` 指向 beta，所有者知悉后选择完成该批发布。此状态不改变业务应用生产部署门禁。
