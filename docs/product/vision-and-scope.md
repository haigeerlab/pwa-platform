# 愿景与范围

## 愿景

提供公司级 PWA 基础设施，让多个 Vue、React 和 SSR 应用无需复制 Service Worker 代码，也不会削弱缓存安全性。

## 使用者

- 维护运行时和适配器的平台工程师。
- 声明离线与更新意图的产品前端团队。
- 安全部署 Service Worker 产物的基础设施与发布团队。

## 首期交付结果

1. 用户访问过的应用可在离线时重新打开，应用壳不白屏。
2. 静态应用壳资源采用可评审的预缓存策略。
3. 默认等待用户的安全操作后才完成更新。
4. 构建产物会校验 manifest、Service Worker、离线降级、身份和拒绝规则。

## 首期非目标

- 所有路由或 API 的通用离线支持。
- 缓存私有账号、支付、直播、WebSocket、令牌或写操作流量。
- 离线写操作重放或冲突解决。
- 视频或媒体下载。
- Push 通知投递基础设施。
- Vue 2 或 React 18 兼容性。
- 在未选定目标路由器、构建器和版本矩阵前提供 Next.js 适配器。
- 公共 JSON/API 响应运行时缓存；它是后续单独评审的能力。
- 任何私有数据缓存；v1 的登出清理只会移除平台会话元数据。
