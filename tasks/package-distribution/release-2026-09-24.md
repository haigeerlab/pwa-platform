- **与最初候选对比（2026-09-24，`4c5f1c1`）**：逐包 `pnpm pack` 后，七个包的 tarball 与最初候选逐字节相同；`client-runtime` 与 `vite` 的 tarball 字节不同，解包比较后只有 `package.json` 不同，差异仅为依赖键的顺序，解析后的 JSON 完全相等，其余文件逐字节相同。全新临时项目以新 tarball 重做 `file:` 安装与 17 个入口的导入检查，结果与上文相同。
