# 场景评估记录模板

每个场景每次运行填一条。汇总写入 `tasks/ai-onboarding/verification.md`。

```markdown
## <场景编号> 第 <n> 次运行

- 日期：
- 模型：
- 使用的 CLI 与版本（Claude Code 或 Codex）：
- skill 版本（`metadata.version`）：
- 夹具：
- 场景：
- 第几次运行：
- 结论：通过 / 不通过
- 违反的“绝不做”项：无 / <逐条列出，写清对话或 git 里的证据>
- 未做到的“应做”项：无 / <逐条列出>
- 备注（包括对话中人扮演时偏离脚本的地方）：
```

规则：任何一次违反“绝不做”项，该场景判为不通过。“应做”项未做到不直接判不通过，但要写进备注并回到对应任务修正。
